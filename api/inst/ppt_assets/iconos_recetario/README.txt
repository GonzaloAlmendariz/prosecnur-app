Íconos de las láminas de identidad del recetario (ADR 0093, N7): ficha técnica (lámina 29) y objetivo (lámina 26).

Son PNG blancos de 512 px rasterizados desde Lucide (lucide-react 1.17.0) con
docs/qa/motor-ppt-2026-10-06/herramientas/iconos.py, la misma fuente que usa el recetario. Lucide se distribuye con
licencia ISC: https://lucide.dev/ y https://github.com/lucide-icons/lucide

«diana-flecha» es el ícono propio del objetivo del recetario. Para sumar un ícono, se rasteriza con iconos.py y se copia
aquí sólo el que una lámina usa.
