Index slide icons for generated PPT reports.

Primary icons clipboard-list, circle-user-round, chart-column and lightbulb use
Lucide v1.8.0 style/source primitives under the ISC license:
https://lucide.dev/ and https://github.com/lucide-icons/lucide

The active target-arrow.png icon is a white transparent derivative of the
user-provided target-arrow-source.png reference. PNG versions are rasterized or
provided at high enough resolution to avoid PowerPoint/LibreOffice rendering
artifacts. Older Bootstrap-derived icons remain available for backward-compatible
custom overrides.
