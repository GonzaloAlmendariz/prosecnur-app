Este índice conserva la trazabilidad de auditorías, matrices, planes y bitácoras
fechadas sin presentarlas como estado vigente del producto. Las treinta fuentes
originales no se borraron ni se movieron: cada una está marcada como
`Histórico`, enlaza su síntesis y permanece disponible para reconstruir la
decisión o la evidencia de su momento.
